# CAL-db: Categories, Algebras and Logics

This collection of GitHub markdown pages contains information about classes of universal algebras, the corresponding logics, and related categories.

The main page is [files/index.html.md](files/index.html.md).

Contributions are welcome: clone the repository, edit or add pages, and submit a pull request.

## How to cite

If you use CAL-db in your work, please cite the database as a whole. GitHub's **"Cite this repository"** button (right sidebar) gives APA and BibTeX versions generated from [CITATION.cff](CITATION.cff).

**BibTeX**

```bibtex
@misc{CALdb,
  author       = {Jipsen, Peter and others},
  title        = {{CAL-db}: Categories, Algebras and Logics},
  year         = {2026},
  howpublished = {\url{https://github.com/jipsen/CAL-db}},
  note         = {Accessed YYYY-MM-DD}
}
```

**Plain text**

> P. Jipsen et al., *CAL-db: Categories, Algebras and Logics*, https://github.com/jipsen/CAL-db (accessed YYYY-MM-DD).

### Citing a single page

Pages are edited over time, so give the access date and, ideally, a permalink to the version you used. On a GitHub page, press `y` to turn the URL into a permalink that contains the commit hash. For example:

> "Hoops", in P. Jipsen et al., *CAL-db: Categories, Algebras and Logics*, https://github.com/jipsen/CAL-db/blob/<commit>/files/hoops.md (accessed YYYY-MM-DD).

### Background

The database grew out of the project described in P. Jipsen, *An online database of classes of algebraic structures*, talk at the Annual Meeting of the Association for Symbolic Logic, Chicago, June 2003 (see [Acknowledgements](files/acknowledgements.md)).
