###  This page has some links to programs useful for manipulating mathematical structures 

  *[ GAP: Groups, Algorithms and Programming](http://www-gap.dcs.st-and.ac.uk/~gap/)
  *[ LatDraw: A lattice drawing Java applet](http://www.math.hawaii.edu/~ralph/LatDraw/) by Ralph Freese
  *[ MACE: a program that searches for small models](http://www.cs.unm.edu/~mccune/prover9/) by William McCune
  *[Maude: A term-rewriting system](http://maude.cs.uiuc.edu/)
  *[Minion: A constraint satisfier](http://minion.sourceforge.net/)
  *[Minisat: A boolean satisfaction solver](http://www.satlive.org/)
  *[ Nauty: a program for computing automorphism groups of graphs and digraphs](http://cs.anu.edu.au/~bdm/nauty/) by Brendan McKay
  *[ Prover9: An Automated Deduction System](http://www.cs.unm.edu/~mccune/prover9/) by William McCune
  *[ Sage Mathematical Software](http://www.sagemath.org) The Sage Group, lead by William Stein
  *[ UACalc: The universal algebra calculator](http://www.math.hawaii.edu/~ralph/software/uaprog/) by Ralph Freese and Emil Kiss
