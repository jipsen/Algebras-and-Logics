# FL$_c$-algebras

Abbreviation: **FL$_c$**

## Definition
A ***FL$_c$-algebra*** is an [FL-algebra](fl-algebras.md) $\mathbf{A}=\langle A, \vee, \wedge, \cdot, 1, \backslash, /, 0\rangle$ such that

$\cdot$ is ***contractive***:  $x\le x\cdot x$
